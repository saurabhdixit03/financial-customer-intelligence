# Financial Customer Intelligence

A data engineering and analytics project that transforms raw financial customer data into clean, reliable, and meaningful insights for understanding customer financial behaviour and loan readiness.

## Problem Statement

Financial institutions generate large volumes of customer account, transaction, and repayment data. Raw records alone do not provide a clear picture of a customer's financial behaviour or readiness for credit.

This project builds a data pipeline to ingest, validate, clean, transform, and analyze financial data to create customer-level insights and an explainable loan-readiness assessment.

> This project uses synthetic data and is intended for educational and portfolio purposes. The loan-readiness assessment is not a real lending decision model.
